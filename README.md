# Task-Scheduler
🌟 Overview

This is a task scheduling web application built with React and Node.js. It allows users to create, edit, and manage tasks efficiently. The app includes features such as reminders, due dates, and task categorization, making it a perfect tool for productivity.

🔥 Features

✅ Task Creation & Editing – Add new tasks, edit descriptions, and set priorities
✅ Due Dates & Reminders – Schedule tasks and receive reminders for upcoming deadlines
✅ Task Categorization – Organize tasks by categories (Work, Personal, etc.)
✅ Mark Tasks as Completed – Track your progress by marking tasks as done
✅ Priority Sorting – Sort tasks by priority or due date
✅ User Authentication – Secure sign-in for personalized task management
✅ Real-time Notifications – Alert users about task reminders
✅ Responsive Design – Optimized for both desktop and mobile views
✅ Persistent Storage – Tasks saved to local storage or a backend database
